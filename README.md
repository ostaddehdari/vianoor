# ویانور | Vianoor

پلتفرم چندزبانهٔ مشاوره، پاسخ‌گویی دینی و منبر آنلاین.

## وضعیت

مرحلهٔ ۱ از ۲۰: معماری اجرایی و آماده‌سازی Monorepo.

- Next.js + NestJS + PostgreSQL + Redis + NATS/JetStream + LiveKit
- میکروسرویس از ابتدا؛ مالکیت مستقل داده‌ها
- فارسی و انگلیسی؛ ورود اصلی با ایمیل و رمز عبور
- ارائه‌دهندهٔ اولیهٔ AI: GapGPT با آدرس، کلید و مدل قابل تنظیم

این نسخه هنوز محصول عملیاتی نیست. تغییرات مرحلهٔ اول در شاخهٔ اختصاصی تکمیل می‌شوند.
