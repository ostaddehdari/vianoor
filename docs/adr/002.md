# ADR-002: مالکیت داده و چندسازمانی

وضعیت: پذیرفته‌شده برای طراحی مرحلهٔ ۱.

## تصمیم

شناسه tenant معتبر از هویت و عضویت حل می‌شود. هر سرویس credential مستقل و کنترل مجوز منابع خود را دارد. Gateway دیتابیس دامنه ندارد.

## پیامد

هیچ join بین پایگاه‌ها نیست؛ نماهای مرکب با API یا projection ساخته می‌شوند.
