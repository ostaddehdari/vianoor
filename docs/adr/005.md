# ADR-005: درگاه AI و مدل قابل تنظیم

وضعیت: پذیرفته‌شده برای طراحی مرحلهٔ ۱.

## تصمیم

فقط AI Gateway اجازه ارتباط با GapGPT دارد. انتخاب capability به مدل نگاشت می‌شود. کلید فقط backend و secret reference است.

## پیامد

base URL نیازمند HTTPS و کنترل SSRF/egress، کلید در log ممنوع؛ AI وابستگی حیاتی رزرو نیست.
