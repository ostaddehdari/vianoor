# پیش‌نویس قرارداد APIهای اصلی

وضعیت: **طراحی‌شده، هنوز پیاده‌سازی نشده**. این مسیرها در OpenAPI اجرایی مرحلهٔ اول منتشر نمی‌شوند. مرجع اجرا فقط `openapi.json` است. در مرحلهٔ مالک، schema کامل request/response، محدودیت‌ها و آزمون قرارداد به API فعال افزوده می‌شود.

تمام مسیرها زیر `/api/v1` هستند. پاسخ‌ها envelope مشترک و trace_id دارند؛ شناسه‌ها UUID، پول Money و زمان UTC است.

مبلغ پرداخت از قیمت نسخه‌دار رزرو استخراج می‌شود؛ مبلغ ارسالی مرورگر مرجع مالی نیست. ثبت API secret باید از جریان امن backend/secret manager انجام شود؛ دریافت `secret_ref` به معنای نمایش یا ارسال کلید خام به کلاینت نیست.

آدرس provider باید علاوه بر schema، در سطح شبکه و DNS در برابر SSRF کنترل شود؛ HTTPS به‌تنهایی کافی نیست. default_model_id الزاماً با مدل هر capability یکسان نیست. تست اتصال هزینه دارد و rate limit و ثبت audit می‌خواهد.
