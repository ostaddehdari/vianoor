# مرحله ۱۲ — وضعیت آزمون

وضعیت: پیاده‌سازی در حال اعتبارسنجی؛ نصب عمومی انجام نشده است. نسخه عمومی پروژه به V12 تغییر داده نشده است.

## شواهد ثبت‌شده

- بررسی مرزهای معماری، ESLint و TypeScript رابط کاربری اجرا شد.
- ۵۳ آزمون موجود پروژه گذشت.
- سه آزمون جدید `tests/communications.test.ts` گذشت: یکسان‌بودن فرهنگ فارسی/انگلیسی و قرارداد پیوست/صوت؛ رمزنگاری و جلوگیری از انتقال داده به رکورد دیگر؛ قرارداد Twilio با سرور HTTP شبیه‌ساز روی loopback (فرم، احراز هویت، تأیید شماره، وضعیت ارسال و خطای ارائه‌دهنده).
- `npm run check` با exit code 0 گذشت: معماری، ESLint، ۵۳ تست، ساخت همه ۳۲ سرویس و هر دو برنامه، TypeScript همه workspaceها. سه تست جدید ارتباطات جداگانه با exit code 0 گذشتند.
- `npm run smoke` با exit code 0 گذشت: زنده‌بودن ۳۲ سرویس در حالت scaffold (readiness بدون زیرساخت عمداً 503) و صفحات فارسی/انگلیسی وب و ادمین. این smoke اثبات عملکرد پیام‌رسانِ متصل به دیتابیس نیست.
- لاگ‌های محلی ignored: `.cache/stage12-local-check.log` و `.cache/stage12-smoke.log`.

## آزمون یکپارچه آماده، اجرا تأیید نشده

`tests/integration/communications.test.ts` فقط با `COMMUNICATIONS_TEST=1` و نشانی اختصاصی محیط آزمایشی اجرا می‌شود. PostgreSQL، Redis، Mailpit و اسکنر واقعی استفاده می‌شوند؛ داده‌ها مصنوعی‌اند.

سناریو: ثبت‌نام و تأیید ایمیل؛ کانال و نظر؛ جلوگیری از دسترسی استاد پیش از ارجاع؛ ۱۰۰ ارسال هم‌زمان با ترتیب یکتا و بازیابی تاریخچه؛ ۱۰ retry یک درخواست؛ claim و ارجاع ادمین؛ Reply و read؛ پرسش خصوصی و ممنوعیت خواندن توسط ادمین؛ پیوست اسکن‌شده و ممنوعیت دانلود غیرعضو؛ نسخه عمومی ناشناس پس از رضایت و تأیید؛ WebSocket و بلیط یک‌بارمصرف؛ حضور و اعلان پایدار.

هنوز **موفقیت این سناریو، بار ۱۰۰ پیام، تست مرورگر/میکروفن و نصب سرور ادعا نمی‌شود**. اجرای تست با آماده‌سازی سرور متوقف شد: کمبود دیسک با حذف فقط ایمیج‌های قدیمی و بدون استفاده ویانور تا حدود ۲٫۹ گیگابایت آزاد برطرف شد؛ سپس SSH مرتباً در banner exchange timeout/reset داد. آخرین بررسی موفق، سرویس‌های V11 را سالم نشان داد؛ بررسی بعدی سایت از این محیط نیز timeout شد، بنابراین وضعیت فعلی سایت نامشخص است.

## مرز اتصال واقعی

WebSocket، صف PostgreSQL، نگهداری حضور Redis و اسکن File Service کد اجرایی دارند؛ آزمون یکپارچه آن‌ها هنوز لازم است. Twilio فقط آزمون قرارداد شبیه‌سازی‌شده دارد؛ حساب واقعی و ارسال SMS تست نشده است. SMTP از مالک identity استفاده می‌شود؛ تحویل واقعی اعلان‌های جدید هنوز باید بررسی شود. تماس صوتی/تصویری، Push و جست‌وجوی خصوصی OpenSearch در این مرحله فعال نشده‌اند.
