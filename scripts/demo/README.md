# Vianoor Demo Seed

`seed-stage21.mjs` creates a comprehensive acceptance-test dataset identified as `DEMO-SEED-21`.

It is intentionally deterministic and idempotent.

Contents:

- 20 verified public experts
- multilingual expert profiles
- two published services per expert
- demo specialties and categories
- real weekly expert calendars
- online / away presence states
- 100 published questions and answers
- 12 scheduled bookings for `dashboard-account@srun.ir`
- completed, future, rescheduled, cancelled and expired booking states
- four session requests
- booking events and unread notifications
- 8 booking conversations
- more than 50 encrypted messages
- 6 completed-session ratings
- successful, failed and refunded payment history
- wallet top-up, purchases, releases and refund through the real wallet/accounting workflow
- search-index generation refresh

Demo account:

`dashboard-account@srun.ir`

Credentials are written only to `/root/vianoor-demo-seed-21/demo-credentials.txt` by the server runner and are never committed to Git.
