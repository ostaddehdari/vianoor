# هویت | identity-service

مرحلهٔ ۴: ثبت‌نام/ورود ایمیلی، تأیید ایمیل، بازیابی رمز، Argon2id، نشست چرخشی و محدودیت تلاش. مالکیت دیتابیس فقط `identity_db` با role مستقل `identity_app` است.

فعال‌سازی نیازمند `AUTH_ENABLED=1` و تنظیمات هویت و زیرساخت است؛ بدون آن scaffold مرحلهٔ قبل حفظ می‌شود. `/health/ready` با فعال بودن هویت و سلامت زیرساخت 200 است. SMTP صف مستقل دارد و این endpoint تحویل ایمیل بیرونی را تضمین نمی‌کند.

راهنمای مسیرها، قراردادها، تنظیمات و آزمون: [مرحلهٔ ۴](../../docs/stages/04-identity.md).

MFA و روش‌های ورود جایگزین مربوط به مرحلهٔ ۵ هستند. هیچ نقش مدیریتی با ثبت‌نام عمومی اعطا نمی‌شود.
